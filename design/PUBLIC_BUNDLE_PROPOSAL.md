# Public bundle - proposed allowlist

Status: **proposal updated for Phase 1**. The registry, subject-scoped routes
and download naming are implemented locally; the document bundle is generated
before the Phase 4 R2 upload.

## Files that would be in the public bundle

```text
public/
  index.html
  csc662/index.html
  csc662/library/index.html
  csc662/generate/index.html
  gallery/index.html
  paused/index.html
  assets/style.css
  assets/htmx.min.js
  assets/library.js                     # filter + column sort
  subjects/CSC662/subject.json          # public-safe fields only
  subjects/CSC580/subject.json          # coming_soon stub
  subjects/CSC645/subject.json          # coming_soon stub
  library/manifest.json                 # subject index
  library/CSC662/manifest.json          # seed, mode, computed marks,
                                        # placeholders, topic mix, file ids
  library/CSC662/papers/CSC662 Seed 01 2026.docx
  library/CSC662/papers/CSC662 Seed 01 2026.pdf
  ...
  library/CSC662/schemes/CSC662 Seed 01 2026 - Marking Scheme.docx
  library/CSC662/schemes/CSC662 Seed 01 2026 - Marking Scheme.pdf
  ...
  static/gallery-shell.html
```

No thumbnails are needed for the v2 table-list Library. Papers and schemes are
generated by `scripts/build_public_bundle.py` after applying PUBLIC_BUILD:

- original local-build cover (university name, crest and reference code);
- schemes omit verbatim slide quotes;
- no user-provided text (seed numeric, mode enum).

## Forbidden from the bundle

```text
data/reference/<SUBJECT>/       # source template/crest files (rendered covers allowed)
data/papers/                    # past-paper working copies
CSC662/                         # original papers
lecture slides / decks / OCR    # any format
.env
Wrangler secrets / API keys
outputs/eval_final_deepseek/    # raw planner/theory JSON
outputs/web_cache/              # private cache
tests/
internal reports / logs
```

The Phase 0 check must fail if a forbidden path appears in the manifest.

## Rules

- Build from an explicit allowlist, never by excluding from a full tree.
- Public gallery shell contains no shared-paper data; the Worker/KV resolves
  unguessable ids.
- Shared files live under R2 `shared/` with a 7-day lifecycle rule.
- Public build carries no live-generation API key and no private Library data.
- If live generation is enabled, it runs server-side behind Turnstile and
  per-IP/global cost caps.
