## Database rules for V2

- SQL/code text is kept exactly as extracted; indentation and line breaks are
  preserved and no SQL is “fixed”.
- A native table is accepted only when the PDF text layer and MinerU HTML agree
  on every row's token sequence and cell count; otherwise the crop is kept.
- ER diagrams, flowcharts, figures and code images are cropped from the source
  page; captions and positions link them to their question.
- Unresolved Figure/Table references, missing sub-parts and mark mismatches are
  reported in `bank/unsure.json`, never invented.
