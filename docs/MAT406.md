## Lifecycle

Read `docs/SUBJECT_PLAYBOOK.md` before changing this subject, then
`subjects/MAT406/lifecycle_state.json`. Run:

```bash
uv run python -m scripts.lifecycle_status MAT406
```

The current work item is **Gate B**. The playbook has three
human gates: **A** (bank approved), **B** (first seeds approved) and **C**
(publish). Do not set the registry status to `available`, publish, upload or
deploy until Gate C is recorded.

Every question in a generated paper must be an approved real past-paper
question from the bank. Generators are off (`variants.enabled` is false).
