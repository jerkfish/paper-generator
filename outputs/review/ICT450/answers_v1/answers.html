a) Briefly describe any FOUR (4) components of database system environment. b) Millions of people all over the world access the internet and connect to databases via web browsers or data services. For example, they can use a smartphone application to get weather or traffic information. Provenance: model_unofficial · confidence high

A database system environment is made up of the people, procedures, data, hardware and software that work together to manage and use a database.

(a)Four components of a database system environment.(8 marks)
  • Hardware — the physical devices on which the database runs, including servers, storage, network equipment and user terminals.
  • Software — the DBMS, application programs, utilities and development tools that let users define, access and manage the data.
  • People — the database administrator, designers, analysts, programmers and end users who use or manage the database.
  • Data — the raw facts stored in the database, together with the metadata that describes their structure and meaning.
  • Procedures — the written instructions and policies for using, backing up, securing and recovering the database.
(b)Four characteristics of successful Internet-age databases.(8 marks)
  • Ubiquitous connectivity — users can reach the database from web browsers, mobile apps and data services at any time and from any location.
  • Scalability and performance — the system can handle growing volumes of users, transactions and data without unacceptable response times.
  • High availability and reliability — the database remains accessible through failures, with replication, backup and recovery facilities.
  • Security and privacy — authentication, authorisation, encryption and auditing protect data that is exposed over public networks.
  • Manageability — the database can be monitored, tuned and administered centrally with minimal disruption.
(c)Two advantages and two disadvantages of an ERD.(4 marks)
  • Advantage: an ERD gives designers, programmers and users a clear visual model of the entities, attributes and relationships before implementation.
  • Advantage: it is independent of any DBMS, so the same conceptual design can be reviewed and implemented on different platforms.
  • Disadvantage: a large ERD can become crowded and difficult to read, especially when many relationships and weak entities are involved.
  • Disadvantage: an ERD does not show every business rule, process or physical implementation detail, so it must be supported by other documentation.

Marking guide

  • a) 2 marks for each of four components named and explained (4 × 2 = 8).
  • b) 2 marks for each of four characteristics named and explained (4 × 2 = 8).
  • c) 1 mark for each advantage and each disadvantage, correctly explained (4 × 1 = 4).

Assumptions

  • The question asks for four components; five are listed so the answer remains complete if the marker expects a different set.

        a) The database life cycle (DBLC) process moves through a series of well-defined phases. i) Briefly explain what the implementation and loading phase do. ii) Describe the THREE (3) levels of backup that used in database recovery management in this phase. b) Briefly describe big data and THREE (3) technologies for managing and analyzing the big data. c) Briefly describe the key difference between unstructured and structured data. Provide an example for each answer.
        Provenance: model_unofficial · confidence high

        Model-authored from the approved question text, the supplied source assets and the ICT200/ICT450 knowledge base; no official ICT450 marking scheme was supplied.

        (a)Database life cycle phases.(8 marks)
        • i) Implementation and loading: the physical database is created from the design — tables, keys, constraints, views, indexes and security are defined; existing data is converted and loaded; backup and recovery arrangements are put in place and the database is tested before release.
        • ii) Three backup levels:
        • Full backup — a complete copy of the whole database; it is the baseline for recovery but takes the most time and space.
        • Differential backup — copies only data changed since the last full backup; recovery needs the last full backup plus the latest differential backup.
        • Transaction-log backup — copies the transaction log, allowing point-in-time recovery and recovery of changes made after the last full or differential backup.
        • Incremental backup may be accepted in place of differential backup: it copies changes since the last backup of any type.
        (b)Big data and three technologies for managing it.(8 marks)
        • Big data is data that is too large, fast-changing or varied for traditional relational systems to capture and process within an acceptable time. Its core characteristics are volume, velocity and variety; veracity and value are often added as extended characteristics.
        • Hadoop and HDFS — Hadoop is a Java-based, open-source, fault-tolerant distributed framework; HDFS is its distributed file system for storing very large files across a cluster.
        • MapReduce — an open-source programming API that processes large datasets in parallel and provides fast data-analytic services.
        • NoSQL — a large-scale distributed database system that stores structured and unstructured data efficiently, with high scalability, availability and fault tolerance.
        (c)Structured versus unstructured data.(4 marks)
        • Structured data has a predefined schema and is stored in rows and columns with consistent data types; it is easy to query with SQL. Example: a student table containing StudID, Name and CGPA.
        • Unstructured data has no predefined relational schema and cannot be stored naturally in rows and columns. Example: images, video, audio, free-text documents or social-media posts.

        Marking guide

        • a)(i) 2 marks for a correct description of implementation and loading.
        • a)(ii) 2 marks for each of three backup levels correctly described (3 × 2 = 6).
        • b) 2 marks for the definition of big data; 2 marks for each of three technologies (2 + 3 × 2 = 8).
        • c) 2 marks for structured data with an example and 2 marks for unstructured data with an example (2 + 2 = 4).

        Assumptions

        • The three backup levels are interpreted as full, differential and transaction-log backup, the standard DBLC recovery model.
